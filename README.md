# Ubaid Desai — Portfolio

Use a patched Node.js runtime matching package.json engines (Node 24.22.1 or later in the 24.x line). npm package updates do not update Node itself.

Personal portfolio site, built with Next.js (static export) and deployed to
GitHub Pages at https://gamerdubz.github.io.

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm run test
```

## Build

```bash
npm run build
```
